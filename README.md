# VEX Robotics Competition: High Stakes 2024-2025

This repository contains the code for my VEX Robotics Competition robot for the game High Stakes 2024-2025.

## Description

This project includes all the necessary code to control and operate the robot designed for the High Stakes 2024-2025 VEX Robotics Competition. The code is written in C++ using the Purdue Robotics OS in combination with Lemlib and is designed to work with the VEX V5 system.

## Installation

1. Clone this repository to your local machine:
    ```sh
    git clone https://github.com/riptideiv/xr_c_highstakes.git
    ```
2. Open the project in Visual Studio Code.

## Usage

1. Connect your VEX V5 Brain to your computer.
2. Compile and upload the code to the VEX V5 Brain using the PROS extension for VSCode.
3. Operate the robot and run autonomous routes using the VEX V5 Controller.
