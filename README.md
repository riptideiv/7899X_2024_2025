# VEX Robotics Competition: High Stakes 2024-2025

This repository contains my code for 7899X's VEX Robotics Competition robot for the game High Stakes 2024-2025.

## Description

This project includes all the necessary code to control and operate our robot designed for the High Stakes 2024-2025 VEX Robotics Competition. The code is written in C++ using the Purdue Robotics OS in combination with Lemlib and works with the VEX V5 system.
